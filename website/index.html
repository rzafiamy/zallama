🦙 A self-contained local AI ecosystem

The local AI gateway
you've been waiting for.

Zallama is a cute, memory-aware, multimodal local AI gateway powered by llama.cpp, parakeet.cpp, and kokoro.cpp. Spin up servers dynamically, query OpenAI-compatible text/vision/voice endpoints, and let Zallama automatically unload models to fit your memory budget.

Get Zallama (Free) Try the eviction visualizer ✨

One-line installation

git clone https://github.com/rzafiamy/zallama.git && cd zallama && sudo bash install.sh
💭 Why we built Zallama

Running local AI
shouldn't mean babysitting it.

llama.cpp, parakeet.cpp, and kokoro.cpp are each fantastic on their own — but juggling separate binaries, ports, and memory limits by hand gets old fast. Zallama's answer is simple: one daemon, one OpenAI-compatible endpoint, and an automatic memory manager that decides what stays loaded.

🧠

One gateway, every modality

Text, vision, speech-to-text, and text-to-speech all speak the same OpenAI-compatible API, on the same port, from the same daemon.

⚖️

Memory-aware by design

Set a RAM/VRAM budget and Zallama evicts the Least-Recently-Used model server automatically — no more manually killing processes to make room.

💻

A real CLI, not an afterthought

zallama serve, pull, run, ps, and set — everything you need to manage models, scripted into your workflow.

🔓

100% local, 100% yours

No cloud calls, no telemetry, no API keys required by default. Zallama runs entirely on your own hardware, from your own model files.

Multilingual ASR

Zallama wraps parakeet-server to serve /v1/audio/transcriptions. Upload MP3, WebM, M4A, or FLAC — Zallama auto-transcodes with ffmpeg and transcribes instantly.

parakeet.cpp under the hood

Vision (Multimodal)

Attach an mmproj projector artifact in your model registry and Zallama binds it automatically — analyze images natively through chat completions.

Local Speech Synthesis

Generate lifelike voices locally with a standalone kokoro-server built on kokoro.cpp, statically linked against ONNX Runtime for easy deployment.

kokoro.cpp under the hood
⬇️

Accelerated Downloads

Zallama leverages aria2c for 8-threaded downloads, falling back to a parallel Python HTTP engine. Pull presets or any Hugging Face file directly.

Auto-detects ASR & TTS models
🔌

OpenAI-Compatible API

Point any OpenAI SDK, LangChain, or agent framework at Zallama by simply changing the base URL — chat, vision, transcription, and speech all just work.

Drop-in replacement

Get Zallama running

The installer compiles llama.cpp, parakeet.cpp, and kokoro.cpp, sets up a Python virtual environment, and registers Zallama as a systemd service. 

git clone https://github.com/rzafiamy/zallama.git
cd zallama
sudo bash install.sh

Compiling each engine separately, running without root, or setting up the systemd unit by hand? The full step-by-step build guide lives in the docs.

Pull Models in One Command

Presets, direct Hugging Face files, or custom ASR/TTS models — zallama pull handles it all.

Unsloth Llama 3.2 3B Preset

Preset ID: llama3.2:3b

zallama pull llama3.2:3b

Custom Hugging Face Model File

Qwen2.5 Coder Instruct GGUF

zallama pull unsloth/Qwen2.5-Coder-7B-Instruct-GGUF/Qwen2.5-Coder-7B-Instruct-Q4_K_M.gguf

Parakeet Multilingual v3 ASR

Transcribe French, Spanish, German, etc.

zallama pull mudler/parakeet-cpp-gguf/tdt-0.6b-v3-q8_0.gguf

Kokoro v0.19 82M TTS Model

Voice synthesis for English/French/etc.

zallama pull kokoro:82m
💡 Pro tip: ASR and TTS GGUF models are auto-detected and registered based on filenames. Force it with --type when pulling a custom model (e.g. --type tts).
